# Pinned on purpose.
#
# This project was previously installed from unpinned ranges, so every rebuild
# picked up whatever was newest on PyPI. That is how a deploy ended up on
# SQLAlchemy 2.1 -- which changed the default driver for "postgresql://" URLs
# from psycopg2 to psycopg v3 -- and crashed with ModuleNotFoundError while
# local environments still worked on 2.0. Pin, test, then bump deliberately.
#
# Keep these versions in sync with pyproject.toml.

# "postgresql://" URL, psycopg2 is what 2.0 uses and what explicit
# "postgresql+psycopg2://" URLs need. Both are small; keep both.
psycopg[binary]==3.3.9
